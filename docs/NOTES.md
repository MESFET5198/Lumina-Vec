# 实现说明与实验记录

README 只写用法。这里记录每一步的做法、为什么这样做，以及试过但放弃的方案。

## 处理流程

```
原图 ─► AI 去颗粒 ─► 均值漂移压平 ─► [线条层] ─► 明暗分层 ─► [打印清理] ─► vtracer 描摹 ─► [细节补回] ─► SVG
```

### AI 去颗粒（`denoise.py`）
先缩小 1/2，把颗粒平均掉，再用 Real-ESRGAN 动漫模型（`realesr-animevideov3`）放大 4 倍，重新生成锐利的线稿。有 CUDA 时自动用 GPU + fp16。

### 明暗分层（`bands.py`）
- **为什么需要**：vtracer 靠合并相似的相邻像素来长出区域。在平滑渐变上，这种合并会一路链式连下去，最后变成一整块纯色，调 `layer_difference` 也没用。所以必须先显式量化颜色。
- **调色板**：在 OKLab 色彩空间做 k-means，默认 112 色，明度权重 1.3、色度权重 2.0。另外为高对比像素单独分配 48 色，让嘴、鼻子这类小细节有属于自己的颜色。采样时压平颜色频率，面积小但颜色独特的区域（虹膜、腮红）也能分到色位。
- **平滑的色带边界**：渐变区像素的归属，由一张避开线稿的模糊图决定。离线稿越远，模糊半径越大（最大 σ=12），之后再做一次空间投票。色带边界因此是平滑的等值线，不是锯齿阶梯，下巴边缘也不会出现浅色晕边。
- **强边缘**（线稿、纹理）保留逐像素颜色。低对比度的小碎块并入邻区，高对比度的小块（高光、鼻点）保留。

### 线条层（`lines.py` + `ink.py`，仅 `shading` / `cel` 默认开启）
1. **哪里是线**：用 ControlNet `lineart_anime` 模型（`netG.pth`）判断，对颗粒不敏感。
2. **线的位置和宽度**：取原图中比周围暗的像素，并且只保留模型也认为是线的部分。模型单独认出的线，只在用来连接两段原图线条、补上缺口时才采用。模型会把虹膜、瞳孔的颜色分界也画成线，直接全部采用会多出原图没有的描边。
3. **重绘**：按"中心线 + 沿线平滑后的半宽"在 2 倍分辨率下重新画出。线宽不超过原图该处的宽度；高光（比周围亮的小块）不会被线条覆盖。
4. **颜色**：取中心线像素中较暗的一半。线条两侧的抗锯齿、色差红边青边都不会影响颜色。颜色相近的线合并为一组。
5. **线条下方的色块**：渐变图用 inpaint 平滑补色，平涂图用最近像素补色。最近像素补色在渐变图上会形成马赛克，平滑补色在平涂图上会生出色带，所以两者分开处理。

干净的厚涂、渐变插画（`shading-detail`）默认不开线条层：这类图原图的线条已经够干净，重绘反而会让睫毛、瞳孔这些地方变重。

### 平涂图（`cel`）
auto 会测量"平缓渐变像素占比"，低于 0.18 就判定为平涂图。平涂图不做渐变平滑（否则硬边高光外会多出一圈晕边），描摹用 cutout 共边模式，颜色数 48，不开细节补回层。

### 细节补回（`overlay.py`）
vtracer 会把很小的色簇并入邻区。一条 3 像素宽的嘴线，因为抗锯齿会被拆成约 10 种颜色，每种只有 1～3 个像素，必然被吞掉。所以按"和局部背景的对比度"重新找出这类小块，每块统一成一种颜色，单独描摹后叠在最上层。

### 打印清理（`--print-mm`）
- 设挤出线宽为 `min_px`。比它窄的颜色区域，按整块判断：如果跟两侧的颜色都明显不同，就是一条线（轮廓、发丝、色差边），整条保留并加粗；如果跟某一侧接近，说明只是抗锯齿过渡，整条并入邻区。判断前，颜色相近、首尾相连的几段会先合成一条。
- 宽区域里比线宽窄的细条交给邻区，图像保持完整覆盖，不会有空洞。
- 线条层的最小线宽等于挤出线宽，短于 4 倍线宽的线会被删掉。
- 描摹用 cutout 共边模式（stacked 模式下各形状单独拟合，接缝处会留下几千条细缝）。每个色块前加一条 `qq3d-gap-filler` 遮缝描边，格式与 Lumina 的过滤代码完全一致，导入 Lumina 时会被删掉，只用来让预览不出现缝隙。

## 实测数据

**打印模式**（同一张图、4 色、Snapmaker U1、263 mm）：

| | 普通 SVG | 打印模式 | 再把回抽最小距离调到 4.5 mm |
|---|---|---|---|
| 预估时间 | 10h04m | 8h56m | 8h28m |
| 外墙小圈 | 32,984 | 23,101 | 23,089 |
| 回抽 | 200,359 | 171,190 | 95,310 |

剩下的时间主要花在实际挤出的体积上（挤出总长约 2 km），这部分 SVG 层面没法再减少。

**平涂图**（2000×2000，按 263 mm 检查小于一个挤出点的区域数）：`shading-detail` 3,606 → `cel` 572，参考 SVG 为 207。

## 试过但放弃的方案

| 方案 | 结果 |
|---|---|
| OKLab k-means + 众数滤波 + 无缝镶嵌 | 指标接近参考，但线稿碎裂 |
| 调低 `layer_difference` 来保留渐变 | 无效：渐变会被链式合并成一块 |
| 分层后做全局平滑 | 毛衣纹理、发丝被抹掉 |
| 只对低对比区平滑，色带边界取自均值漂移结果 | 色带边缘呈阶梯状或块状，打印不了 |
| 用固定 σ 模糊来决定色带 | 线稿渗进皮肤，下巴边缘出现晕边 |
| `filter_speckle=12` | 瞳孔高光、鼻子、嘴被删掉，改为 4 |
| 只按面积找五官 | 抗锯齿把嘴拆成多种颜色，找不到，改为按对比度检测 |
| 线条形状直接取原图暗像素 | 原图边缘本身就毛，描出来还是碎 |
| 线条直接采用模型画的线 | 粗线被画成两条细边；虹膜、瞳孔边界被多描一圈 |
| 线条颜色取全部像素的中位数 | 色差红边把黑线染成红色 |
| 线条颜色取最暗的 1/4 像素 | 所有线条整体偏深 |
| 打印模式逐像素判断窄条 | 一条线被切成断断续续的虚线 |
| 打印模式加粗所有细笔触 | 眼睛被糊成黑块，线条起疙瘩 |
| 线条下方用最近像素补色（渐变图） | 补出马赛克，高光被吞 |
| 高光检测用中值比较 | 线条旁边的普通肤色也被判成高光，留下细缝 |
